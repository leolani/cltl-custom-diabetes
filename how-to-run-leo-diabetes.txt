#### How to run the application:

* start platform and client/backbone images in Docker
* adapt the clients/backbone/config/custom.config to laptop or pepper
* check if monitoring is on in the server/default.config:

[cltl.chat-ui]
name: chat-ui
agent_id: leolani
external_input: True
timeout: 0
# Adds the Image panel beside the conversation: a file input, drag-to-draw
# labelled rectangles, and Submit. Submitting publishes ONE ImageSignalEvent on
# topic_image below and echoes the picture into the transcript — and publishes
# NOTHING on topic_utterance, which is why cltl-eliza never answers a picture
# and an image draws exactly one reply where text draws two.
image_upload: True
image_cache: 4
image_max_size: 10485760
image_types: image/png, image/jpeg, image/gif, image/webp
# Left empty ON PURPOSE: the chat UI falls back to [cltl.backend] storage_url
# below, which is what guarantees that the endpoint it PUTs pixels to is the
# same one everybody else resolves `cltl-storage:` against. Setting it here
# would create a second place for the same address to be wrong in.
image_storage_url:
image_upload_timeout: 30
# The Monitoring tab: an iframe onto the page this tenant's cltl-monitoring
# serves. A browser-reachable URL — see tenant.compose.yml, which builds it from
# the published port. Empty leaves the tab out.
monitoring_url: http://localhost:8005/monitoring


* ./run_host-server.sh from clients/backbone: uses the venv (installs it if not present)

* run the llamacpp with the VLM for object recognition (Codeing/vlm/guff):
-  llama serve -m Qwen3VL-8B-Instruct-Q4_K_M.gguf --mmproj mmproj-Qwen3VL-8B-Instruct-Q8_0.gguf -c 8184 -ngl all --host 0.0.0.0 --port 9009

* run cltl-custom-object-recognition: adapt the KG repo in the config for scene storage
- conda deactivate
- source ./venv/bin/activate
- CLTL_AMQP_URL='amqp://eliza:eliza123@127.0.0.1:5672/' \
CLTL_TENANT=tenant-a \
CLTL_STORAGE_URL=http://127.0.0.1:8001/storage/ \
    python src/main.py

* run cltl-custom-diabetes for driving the conversation: adapt the KG repo for event storage
- conda deactivate
- source ./venv/bin/activate
- CLTL_AMQP_URL=amqp://eliza:eliza123@127.0.0.1:5672/ CLTL_TENANT=tenant-a \
    python src/main.py

* Open the browser chatui: http://localhost:8003/chatui/static/chat.html
